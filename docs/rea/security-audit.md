# Jfred 隐私与安全审计

审计对象：`rea` 分支（Jfred 0.12.0，独立 SwiftUI/AppKit 实现）。
范围：`Sources/Jfred`、`Sources/JfredCore`、`Info.plist`、`Package.swift`、`scripts/`。
方法：全量阅读高风险路径 + `grep` 敏感 API + REA 字符串/符号辅助确认 + 构建与运行验证。

## 结论

没有发现主动外传数据的遥测、分析或第三方 SDK。唯一的网络监听是用户显式开启的 Local Remote HTTP 服务；唯一的外部进程调用是用户命令、工作流、Terminal/AppleScript、`mdfind`、`op` 等本机工具。审计中发现并修复了 8 个可被利用或会泄露本地数据的问题，剩余风险主要来自「用户主动开启的远程页面」和「工作流本身就是可执行代码」这两类设计。

## 已修复

| # | 严重度 | 问题 | 位置 | 修复 |
| --- | --- | --- | --- | --- |
| 1 | 高 | Remote 页面把 `id`、命令标题、设置名等直接拼进 HTML，存在本地 XSS/HTML 注入 | `AppModel.handleRemote` | 所有动态文本经 `escapeHTML`；CSP `default-src 'none'`；`nosniff`；`Referrer-Policy: no-referrer` |
| 2 | 高 | `/run?id=volume:<任意字符串>` 直接拼进 AppleScript，可注入脚本 | `AppModel.performSystem` | 只接受 `0...100` 的整数 |
| 3 | 高 | `.alfredworkflow` 解压前未检查成员路径，恶意 zip 可路径穿越 | `JfredStore.importWorkflow` | 先用 `unzip -Z1` 检查绝对路径/`..`，限制 20,000 个成员；解压后再校验 info.plist |
| 4 | 高 | 联系人 `CNContact.note` 在无 entitlement 时抛 ObjC 异常，直接崩溃 | `ContactsIndex` | 移除 Note key；只读取无需额外 entitlement 的字段 |
| 5 | 中 | `state.json`、`ClipImages`、支持目录默认 0644/0755，同机其他用户可读剪贴板历史与 Remote token | `SupportPaths`、`AppModel.save`、`saveClipboardImage` | 目录 0700，状态/图片 0600；同步目录同样收紧 |
| 6 | 中 | 密码管理器/系统凭据界面复制的内容可能进入剪贴板历史 | `AppModel.pollClipboard` | 默认屏蔽 1Password、Keychain Access、Passwords、Wallet、SecurityAgent、System Settings；保留 Concealed/AutoGenerated/Transient 过滤 |
| 7 | 中 | Remote token 只有 12 字符，且用 `==` 比较；HTTP 监听可被 DNS rebinding 访问 | `Preferences`、`RemoteServer`、`AppModel` | token 至少 24 字符（32 hex）；常量时间比较；`localOnly` 时校验 Host 只允许 localhost/127.0.0.1/[::1]；只接受 GET；增加安全响应头 |
| 8 | 低 | `jfredlocal://` URL 的 `q` 参数无长度上限 | `JfredApp` | 截断到 512 字符 |

## 仍然存在 / 已接受的风险

1. **Remote 使用明文 HTTP。** 当用户关闭 “This Mac only” 时，token 会在局域网中以明文传输。已在 UI 显示红色警告，默认仍是仅本机。需要跨设备使用时，建议只在自己信任的网络，或后续改成 TLS/配对码。
2. **Clipboard 历史是明文数据库。** 已用 0600 限制本机其他用户读取，但没有加密。若把 `syncFolder` 指向 iCloud/Dropbox 等同步目录，历史会随云同步；UI 已提示可退出清空。
3. **工作流可以执行任意 shell / AppleScript。** 这是 Alfred 兼容工作流的固有能力，不是漏洞；只应导入可信来源的 `.alfredworkflow`。导入路径已做 zip-slip 校验，但没有沙箱化脚本执行。
4. **AppleScript / Terminal 是用户显式触发的。** `>` 前缀、Terminal 动作、工作流脚本都会执行用户输入；这是功能本身。已对唯一可被远程触发的 `volume:` 做数值校验。
5. **Accessibility / Automation / Contacts 权限较大。** 这些权限用于窗口命令、浏览器标签、联系人搜索；不授权时对应功能会返回空结果，不会崩溃。
6. **REA/Hopper 逆向仅用于本机互操作。** 没有把 Alfred 的资源、nib、字符串表或反编译代码放进仓库；合规边界见 `docs/rea/README.md`。

## 隐私数据清单

| 数据 | 位置 | 保护 |
| --- | --- | --- |
| 剪贴板历史 | `~/Library/Application Support/JfredLocal/state.json` + `ClipImages/` | 0600/0700，屏蔽密码管理器，可退出清空 |
| 联系人姓名/邮箱/电话/职位 | 内存，运行时从 Contacts 读取 | 不写入 state.json；不读取 note（需要额外 entitlement） |
| Remote token | `state.json` | 0600，32 hex，常量时间比较 |
| 书签/浏览器标签/Chrome profile | 运行时读取 | 仅用于搜索结果，不写盘 |
| 搜索历史/使用统计 | `state.json` | 0600，可关闭 `showLatestQuery` |
| Newsletter 邮箱 | `state.json` | 仅本地保存，Subscribe 按钮不发送网络请求 |
| 工作流/脚本 | `ImportedWorkflows/` | 用户主动导入；脚本按原样执行 |

## 验证

```bash
swift build
./scripts/test.sh          # 16 个测试，全部通过
./scripts/build-app.sh
open build/Jfred.app
```

运行验证覆盖：偏好设置窗口、Features 16 页、Contacts/Music 新页面、Remote 页面启动、剪贴板轮询、联系人权限按需申请（不在启动时弹窗）。

Remote 头验证（本机 127.0.0.1:8910）：

```text
GET  /?token=<32hex>            -> 200，含 CSP / nosniff / Referrer-Policy
Host: evil.example              -> 403 Invalid host
POST /?token=<32hex>            -> 405 Method Not Allowed, Allow: GET
```
