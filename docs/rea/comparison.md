# 截图复刻（main）与 REA 复刻（rea）对比

## 一句话

`main` 是照着 Alfred 截图逐页“搓”出来的可用克隆；`rea` 是在同一代码基线上，用 REA 对 Alfred 5.7 的二进制、nib 图和 Accessibility 树取证后，重新对齐外壳、补齐页面与行为的版本。`rea` 不是把 main 推倒重写，而是把“看起来像”换成“有证据的像”。

## 方法与证据差异

| 维度 | main（截图复刻） | rea（REA 复刻） |
| --- | --- | --- |
| 主要依据 | 截图 + 人工点击 + 试错 | REA 分析 3 个 Mach-O、20,785 + 4,032 条字符串、36,948 + 6,472 个符号、34 个 Feature nib、18 个 Preferences nib |
| UI 结构 | 目测间距、颜色 | nib 图 + AX frame + 像素采样；窗口/rail/list/header/panel 固定尺寸 |
| 页面清单 | 14 个 Features | 16 个 Features（补 Contacts、Music） |
| 偏好项 | 只实现“看得见”的开关 | 从 `Alfred Preferences Defaults.plist` 补键名与语义，新增 50+ 选项字段 |
| 行为证据 | 截图与文档 | `decompile` 关键分支（剪贴板保留、General nib 装载）+ 符号/字符串交叉验证 |
| 安全 | 未系统审计 | 专项审计并修复 9 项；见 `security-audit.md` |

## 界面差异（rea 已对齐）

- 外壳从“Liquid Glass + 极光渐变”改为 Alfred 的平色：`#4F217A` rail、`#2F104B` 列表、`#ECECEC` 内容、`#D9D9D9` 标题栏。
- 启动器按 Alfred `.alfredappearance` 的实测指标重建：默认 559pt 宽、3pt 圆角、9/8pt 内边距、34pt System Light 搜索、18/12/16pt 结果字号、40pt 图标、约 50pt 行高；10 套主题与 Alfred 同名同指标（颜色/尺寸，不复用主题文件或壁纸）。
- 启动器补 Action Panel：→ 或 ⌘K 打开，↑↓ 选择、↩ 执行、Esc/← 返回；App/文件/URL/联系人/剪贴板/计算器各有对应动作（Open、Reveal、Copy Path、Quick Look、Large Type 等）。
- Universal Actions 改为 General / Actions 两 tab，补 Show Actions 的 →/fn/ctrl/⌘ 开关、Selection Hotkey、Action Ordering，Actions 页列出可用动作。
- Snippets 补 Viewer Hotkey、右侧 Auto Expansion 卡片与 Options 面板（展开声音、剪贴板恢复），集合列表加 Get Collections 入口。
- 1Password 页改为 Alfred 的绿色 Integration 卡片 + 1Password 7/8 说明 + 集成开关，并保留基于 `op` CLI 的实际加载与状态。
- Appearance 支持导入/导出 `.alfredappearance`：读取 window/search/result 的数字与颜色字段生成自定义主题，导出为同结构 JSON；自定义主题可删除。
- Clipboard 的 Ignore Apps 列表可编辑并参与轮询过滤；File Buffer 支持超时清理、按配置在动作后清空；联系人 Action Panel 补 Email / Call。
- Appearance 的 Options 面板可把内置主题复制为自定义主题，编辑窗口宽/圆角/内边距/字号/颜色，实时应用并导出。
- 新增统一的 `PageHeaderBand` 与 `FormPanel`：46pt 图标、20pt 标题、12.5pt 副标题、白色圆角表单。
- Features 列表行高 42pt、图标 34pt、宽 240pt，16 项与 Alfred 顺序一致。
- 底部 rail 新增 Powerpack、Help，顺序为 Powerpack / Usage / Help / Update。
- General 页居中表单 + 紫色 Newsletter 底栏（邮箱只本地保存，不联网）。
- Default Results 补 Contacts  essentials、修正 “Folders in Home - Excluding ~/Library”、补 Fallbacks 说明。
- Clipboard 补 History / Merging / Advanced 三页与 Fast append、Auto-paste、Max Clip Size、Concealed/AutoGenerated、Unicode、置顶、退出清空等选项。
- Calculator 补 Advanced（`=`）、Input/Output 小数分隔符、千分位。
- Dictionary 补 Define/Spell/Language/Paste on action/Only dictionary words。
- Terminal 补 Application、Prefix、Custom AppleScript。
- File Search 补 Navigation / Buffer / Advanced 三页的文件夹导航、缓冲区清理、Home Folder、Copy Path、AppleScript、外置盘图标与 Touch 选项。
- System 每个命令补 enable 开关；禁用后搜索结果和 Remote `/run` 都会拒绝执行。
- Appearance 改为 290pt 主题列表 + 80×50 主题缩略图 + 实时启动器预览；Workflows 改为 Alfred 的深色空态画布、五张引导卡片和底部工具栏。
- Workflows 选中工作流后不再是弹出的表单，而是在主窗口内显示画布：Keyword 节点 → Action 节点 → Add Action，右侧白色 Inspector 编辑名称/关键词/作者/图标/颜色或动作类型/值；底部 Add Action / Cancel / Save。
- Workflows 补基础 Debugger：输入测试 query，Run 按顺序执行内部动作并记录结果/输出，底部面板可 Clear/Close；Add Action 改成动作类型菜单，动作可左右移动排序。
- Help 补搜索框、按主题分组的排障说明、Copy Diagnostics 与支持目录/索引计数。
- Workflow action 节点支持拖拽重排（DropDelegate），Inspector 也保留左右移动按钮。
- Clipboard 的 Clear Keyword 真正生效：支持清空全部或最近 5/15 分钟，并可开关该 keyword。
- 启动器 Action Panel 已实测：`jfredlocal://actions?q=co` 可打开并按类型显示 Open/Reveal/Copy Path/Quick Look/Copy Name/Large Type。
- Universal Actions 补全局 ⌥⌘\ 选择动作：读取当前选中文本（Accessibility）或仅在 Finder 为前台时读取选中文件（Automation），弹出 Copy / Large Type / Open as URL / Search the Web 等动作；`jfredlocal://selection` 可手动触发。
- Workflows 画布左侧新增 Objects 调色板，可直接插入 7 种动作类型；与 Add Action 菜单、拖拽重排、Inspector 并存。
- Workflow Debugger 增加 Step：一次执行一个 action 并记录输出，光标/Finished 状态可见，方便逐步排查。
- Workflow 动作支持断点（Inspector 的 Pause at this action，节点右上红点），Run 会在断点前暂停，再 Run 从暂停处继续。
- 修复删除动作后面板 Picker 仍持有旧 index 导致 `Index out of range` 崩溃：workflow/action Binding 改为带 fallback 的安全读取。
- 偏好搜索索引补齐新入口：主题导入导出、Clipboard Ignore Apps、Snippet Auto Expansion、Workflow Debugger、Universal Actions、Help、Powerpack。
- Help 增加 Clear Clipboard History / Clear Usage Data，便于用户就地清理本地隐私数据。
- Music 补独立的 Mini Player 面板：封面占位、当前曲目/歌手/播放状态、上一首/播放暂停/下一首、音乐库搜索与结果播放；`music` 关键字或 `jfredlocal://music` 可打开。
- Remote 补 “Add iOS Remote” QR 配对面板（本地 URL + token，可复制）与一键 Regenerate Token，仍不实现 Alfred 的私有 iOS 配对协议。
- Contacts、Music 为新增页面，并各自补 Contacts/Email/Advanced 与 General/Keywords/Advanced tab；Music 已接 Play/Pause、Previous、Next、Current Track。

## 行为差异（rea 已接）

- Contacts：`Contacts.framework` 读取姓名/邮箱/电话/职位，进入 `Search` 结果，回车用 `addressbook://` 打开；权限按需申请，不在启动时弹窗。
- Music：`Music.app` AppleScript 播放/暂停/上下曲/按名称搜索播放；`play <song>` 与 `music` 关键词进入结果。
- 剪贴板：默认屏蔽密码管理器；Concealed/AutoGenerated 可配；超过 Max Clip Size 不入库；Auto-paste 可关；使用后置顶。
- Remote：token 32 hex、常量时间比较、Host 校验、CSP、HTML 转义、只接受 GET；非本机监听有红色警告。
- 工作流导入：解压前做 zip-slip 校验。
- 状态/剪贴板文件：0600/0700。

## 仍未对齐（诚实清单）

- Music Mini Player 已有独立窗口与曲目搜索，但没有唱片封面、播放列表/专辑浏览和随机播放逻辑。
- Appearance 已支持 `.alfredappearance` 导入/导出、自定义主题编辑/删除；仍没有 Alfred 的逐控件主题调试器。
- Workflows 的节点自由连线、对象库、断点/单步调试仍是结构级；空态、列表、导入、模板、基础画布、Inspector、拖拽重排与顺序 Debugger 已对齐。
- Remote 的私有 iOS 配对协议、Powerpack/Help 的完整内容仍是结构级（QR 配对面板已有）。
- Alfred 的手绘图标/主题壁纸没有复制（版权与独立性考虑），Jfred 用 SF Symbols + 同色块。
- 少数 Alfred 选项只落了 UI 与偏好字段，未逐一接行为（例如 File Buffer 的 Shift+Option 变体、Snippets 的完整 Auto Expansion 子选项、Calculator 的高级函数全集）。
- 像素级字体/间距仍有 1–3pt 级差异；REA 证据给出的是 frame 与颜色，不是渲染后的字形度量。

## 复现

```bash
git switch rea

./scripts/test.sh
./scripts/build-app.sh
open build/Jfred.app
```
